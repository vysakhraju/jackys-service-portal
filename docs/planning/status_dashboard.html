Worth knowing

The build session can't reach your machine's network — verification now runs as a script you execute

The environment that builds this code can read and write your project files, but it has no network path to anything running on your machine — confirmed directly (connection refused from every angle, including the gateway IP). Phases 1 and 2's write-ups implied a direct curl call from that side; this phase is the first to actually hit that wall. Fixed with verify-phase3.ps1, a script you run yourself with both dev servers up — it prints PASS/FAIL per real endpoint, you paste back the output, anything that fails gets fixed from that. Same pattern git push already uses. Future frontend phases will use this from the start instead of assuming otherwise.
