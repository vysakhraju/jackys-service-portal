Frontend Phase 2, in detail

All 9 Master Data sub-modules, one shared list+form pattern

A shared DataTable + Modal + Field component set backs all 9 screens, but each screen follows the backend's real REST surface exactly, including its gaps — not a uniform CRUD assumption. Service Centres is the only sub-module with full create/update/delete (with a per-weekday schedule editor); four sub-modules are create-and-list only because no update/delete endpoint exists; Spare Parts, Service Price List, Warranty Master, and Component Yield Matrix each get their own shape (link-to-model action, activity-type picker, check-by-serial lookup, by-model/by-category toggle) because their backend routes don't offer a plain list. Bulk Import stays Swagger-only — no file-upload UX has been designed yet.
